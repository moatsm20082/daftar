# دفتر · Daftar — v7

## الجديد بهالنسخة
- **كل ملف (مشروع) إله نوع شغل وبنود مصاريف خاصة فيه.** مشروع ويب جوا شركة مقاولات ما بيطلعله إسمنت وحديد، وبتقدر تزيد وتشيل بنود.
- **فواتير وصور وملفات** على أي مصروف أو دخل أو سلفة أو طلعة. تخزين خاص لكل شركة، والفتح بروابط مؤقتة.
- **قسم التكسي والتوصيل:** وردية، طلعات حسب التطبيق، عمولة كل تطبيق، والصافي بالطلعة وبالساعة وبالكيلو.
- **سهولة:** أزرار كبيرة بالرئيسية لأكثر شي بينعمل (دوام، مصروف، دخل، سلفة، طلعة)، و"جرّب بمثال" لأول مرة.
- **الفريق:** صاحب الشركة بيضيف المعلّم أو المحاسب أو الشريك برمز دعوة على الواتساب، وبيشيله وقت ما بدّه.
- **الانتشار:** كشف حساب للعميل وللعامل على الواتساب، وزر "شارك دفتر"، وكل رسالة وتقرير عليها رابط دفتر.
- **الدعم:** رسائل لفريقك بس (بدون ذكاء اصطناعي)، وبترد عليها من لوحة الإدارة.
- **الإضافي 125% أو 150%** حسب قانون العمل الأردني.
- **صفحات وأدوات مجانية لجوجل:** `/daily-accounts/` و`/tools/overtime/` و`/tools/salary/` و`/tools/driver/` (بتنبني من `seo/build_pages.py`).

## الترقية
1. **قاعدة البيانات:** SQL Editor ← الصق `supabase/v6-upgrade.sql` ← Run (آمن تشغيله أكثر من مرة).
2. **الموقع:** ارفع كل الملفات (مجلد `docs/` هو الموقع).
3. **Supabase → Authentication → URL Configuration:** Site URL = `https://daftarapp.co/app/`، وRedirect URLs = `https://daftarapp.co/app/**`.
4. **بعد أي تعديل بـ `src/`:** شغّل `./build.sh` (بيبني `docs/app/app.js`).
5. **إذا كنت مركّب المساعد أو بحث الأسعار من قبل:** احذفهم من Supabase ← Edge Functions، واحذف السر `ANTHROPIC_API_KEY`.

## ١) قاعدة البيانات (Supabase)
1. اعمل حساب على https://supabase.com، وبعدها **New project**.
2. افتح **SQL Editor**، والصق محتوى `supabase/schema.sql`، واضغط **Run**.
   - إذا كنت مشغّل نسخة قديمة من الملف، شغّل الجديد فوقها عادي.
3. روح على **Project Settings**، وبعدها **API**. انسخ **Project URL** والمفتاح **anon public**، وحطهم بملف `docs/config.js`.
4. بنفس الملف حط رابط الموقع بخانة `APP_URL`.

> ⚠️ لا تحط مفتاح `service_role` بأي ملف بالواجهة أبداً.

## ٣) الموقع على GitHub Pages
1. ارفع كل الملفات على repo بـ GitHub.
2. روح على **Settings**، وبعدها **Pages**. اختار branch `main`، والمجلد **`/docs`**.
3. بـ Supabase روح على **Authentication**، وبعدها **URL Configuration**. حط الرابط بخانة **Site URL**، وضيفه تحت **Redirect URLs**.

## ٤) إعدادات الحماية بـ Supabase
روح على **Authentication**، وبعدها **Sign In / Providers**، وبعدها **Email**:
- خلّي **Confirm email** شغّال.
- خلّي **Minimum password length** على 8 أو أكثر.
- إذا بلشت تشوف تسجيلات وهمية، شغّل **CAPTCHA** من **Attack Protection**.

## ٥) لوحة الإدارة (مقفولة ومنفصلة)
لوحة الإدارة **مش موجودة بالتطبيق العام أبداً**: ما في زر ولا كود ولا رابط إلها. هي موجودة بمجلد `admin-console/` لحالها.

**الحماية على 5 طبقات:**
1. **حساب أدمن خاص:** إيميل مش مستعمل بأي شركة. قاعدة البيانات بترفض إنه ينربط بأي شركة.
2. **التحقق بخطوتين (TOTP) إلزامي:** قاعدة البيانات بترفض كل طلبات الأدمن إذا الجلسة مش متحققة بخطوتين، حتى لو كلمة السر صح.
3. **مسار مخفي** ما بيظهر بمحركات البحث (`noindex` و`robots.txt`)، ولا بأي مكان بالتطبيق.
4. **الجلسة بالتاب بس:** بتنتهي لما تسكّر التاب، أو بعد 15 دقيقة بدون حركة، أو بعد 8 ساعات بأي حال. والصفحة ما بتشتغل جوا iframe.
5. **سجل أمان:** كل دخول وكل عملية بتنحفظ مع الـ IP والجهاز، وما حدا بيقدر يعدّلها أو يحذفها من الواجهة.

**الخطوات:**
1. اعمل حساب الأدمن من Supabase: روح على **Authentication**، وبعدها **Users**، وبعدها **Add user** (Create new user). حط إيميل خاص وكلمة سر قوية (16 حرف أو أكثر). **لا تسجّله من التطبيق.**
2. بـ Supabase روح على **Authentication**، وبعدها **Multi-Factor**، وتأكد إنه **TOTP** مفعّل.
3. بـ SQL Editor شغّل هالأمر بعد ما تغيّر الإيميل:
```sql
insert into public.platform_admins(user_id) select id from auth.users where email = 'admin-email@example.com';
```
4. حط نفس الرابط والمفتاح العام بملف `admin-console/admin-config.js`.
5. **ارفع اللوحة مكان منفصل، مش على نفس الـ repo العام.** إذا الـ repo عام على GitHub، أي حد بيقدر يشوف المسار. عشان هيك `admin-console/` مضاف لملف `.gitignore`.
   - **الأفضل:** Cloudflare Pages (مجاني):
     - اعمل مشروع باسم عشوائي، مثلاً `ops-290f2ae3e7d53fae2eeabca6`.
     - ارفع محتوى `admin-console/`. ملف `_headers` بيضيف حماية إضافية: منع الـ iframe، و`no-store`، و`noindex`، وHSTS.
     - فعّل **Cloudflare Access** على الرابط (Zero Trust، مجاني لحد 50 شخص)، واسمح لإيميلك بس. هيك ما حدا بيقدر حتى يفتح الصفحة غيرك.
   - **أو:** شغّلها من جهازك بس: `npx serve admin-console`، وبعدها افتح `http://localhost:3000`.
6. أول دخول: إيميل وكلمة سر، وبعدها بيطلعلك **QR**. امسحه بـ Google Authenticator أو Authy، واكتب الرمز. من هون ورايح كل دخول بدو الرمز.

> إذا ضاع تلفونك اللي عليه تطبيق المصادقة: من Supabase روح على **Authentication**، وبعدها **Users**، واختار حساب الأدمن، واحذف الـ MFA factor. بعدها سجّل دخول وفعّله من جديد.

## ٦) التطبيق على الموبايل
- **من المتصفح:**
  - Chrome: افتح القائمة ⋮، واضغط **Install app**.
  - Safari: اضغط زر المشاركة، واختار **Add to Home Screen**.
- **المتاجر:** شغّل هالأوامر على جهازك:
```bash
npm install
npx cap add android && npx cap add ios
npx cap sync
npx cap open android   # Android Studio ← Generate Signed Bundle (.aab)
npx cap open ios       # Xcode ← Archive (على Mac)
```
- لتوليد كل مقاسات الأيقونات: `npx @capacitor/assets generate`.
- **قبل الرفع على المتاجر لازم:** صفحة سياسة خصوصية، وزر حذف الحساب من جوا التطبيق. Apple بتطلبهم.

## ٧) الإيميلات (تأكيد الحساب ونسيت كلمة السر)
الإيميلات بيبعتها Supabase نفسه. عشان تطلع احترافية وما تروح على الـ Spam:

1. **القوالب:**
   - روح على **Authentication**، وبعدها **Emails**، وبعدها **Templates**.
   - **Confirm signup:** الصق محتوى `supabase/email-templates/confirm-signup.html`. والعنوان: `أكّد إيميلك · Confirm your email — دفتر`
   - **Reset Password:** الصق محتوى `supabase/email-templates/reset-password.html`. والعنوان: `تغيير كلمة السر · Reset your password — دفتر`
2. **ربط إيميل من دومينك (SMTP):**
   - إيميل Supabase المجاني محدود (رسائل قليلة بالساعة) ومش للاستعمال الحقيقي.
   - اعمل حساب بخدمة زي **Resend** أو **Brevo** (فيهم خطط مجانية)، وأكّد الدومين.
   - بـ Supabase روح على **Authentication**، وبعدها **Emails**، وبعدها **SMTP Settings**، وحط بياناتهم. اسم المرسل: `دفتر`، والعنوان مثلاً `no-reply@دومينك`.
3. **المدة:** روح على **Authentication**، وبعدها **Providers**، وبعدها **Email**. خلّي مدة الرابط **3600 ثانية** (ساعة)، زي ما مكتوب بالتطبيق.

**كيف بيشتغل:**
- **تسجيل حساب:** بيوصل إيميل "أكّد الإيميل"، والمستخدم بيضغط الزر. بعدها بيدخل وبيختار مجال شغله.
- **نسيت كلمة السر:** بيوصل إيميل فيه زر "اختار كلمة سر جديدة"، والزر بيفتح التطبيق على شاشة كلمة سر جديدة. بعد الحفظ بيدخل على طول.
- **الأدمن** بيقدر يبعت نفس الرابط لأي شركة من لوحة الإدارة.

## الميزات الجديدة بـ v5
- **تسجيل أبسط:** اسم الشركة وإيميل وكلمة سر، مع زر إظهار لكلمة السر. مجال الشغل بيختاره المستخدم بعد الدخول.
- **صفحة "تفقّد إيميلك"** بعد التسجيل أو نسيت كلمة السر، فيها نصايح وزر "ابعته كمان مرة".
- **صفحة المجلد صارت بتبويبات:** اليوم، الرواتب، الفلوس، الخلاصة.
- **أول ما تبلش:** بتطلعلك 3 خطوات بدل الأرقام الفاضية.
- **تصدير Excel** للفلوس وللرواتب، بملفات بتقرأ العربي صح.
- **كشف حساب العامل على الواتساب** برسالة جاهزة. الرقم بيتحول للصيغة الدولية لحاله.
- **طباعة أو PDF** لخلاصة أي مجلد.
- **بحث بالفلوس:** بالاسم أو النوع أو المبلغ.
- **حذف حساب الشركة نهائياً** (Apple وGoogle بيطلبوه)، وصفحة **سياسة الخصوصية** `docs/privacy.html`.

## الحماية
- **كل شركة معزولة بقاعدة البيانات (RLS).** جربت هالشي على Postgres تجريبي: شركة حاولت تقرأ وتعدّل وتحذف بيانات شركة ثانية، وانرفضت كل المحاولات.
- **كلمات السر مشفّرة عند Supabase،** وما حدا بيشوفها.
- **الأدمن بيشوف إحصائيات وأسماء ومعلومات تواصل بس،** ونص التذاكر اللي المستخدم اختار يبعتها للدعم. والدخول بيحتاج التحقق بخطوتين، والقاعدة بتفرضه.
- **المستخدم ما بيقدر يزوّر رسالة على أنها من "فريق الدعم":** قاعدة البيانات بتشيلها.
- **تذاكر الزوار محدودة:** رسالتين بالساعة لكل رقم أو إيميل، و30 رسالة كل 10 دقائق للكل.
- **Content Security Policy:** الموقع ما بيشغّل أي سكربت من برّا، والمكتبة مستضافة عندك.
