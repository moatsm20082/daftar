نزّل دفترجرّب بدون تسجيل

شو بيعملك دفتر

  • بيع بالباركودبالقارئ أو بكاميرا التلفون، ووصل حراري للزبون.
  • مخزون بيمشي لحالهبينقص مع كل بيعة، وبينبهك لما الصنف يخلص أو يقرب ينتهي.
  • ديون وأقساطكشف حساب لكل زبون، وتقسيط الفاتورة على أشهر.
  • نقاط ولاءالزبون بيجمع نقاط وبيرجع يشتري منك.
  • بدون نتالبيع بيتسجّل حتى لو قطع النت، وبيترفع لحاله بعدين.
