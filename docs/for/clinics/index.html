نزّل دفترجرّب بدون تسجيل

شو بيعملك دفتر

  • مواعيد المرضىجدول كل يوم، ومين جاي إمتى.
  • فواتير ودفعاتفاتورة لكل زيارة، والدفعات والأقساط محسوبة.
  • مصاريف وأرباحبتعرف قديش دخلت العيادة وقديش صرفت.
  • رواتب وضمانرواتب الطاقم والضمان الاجتماعي بتنحسب لحالها.
  • بياناتك إلكما حدا بيشوفها غيرك وغير فريقك.

أسئلة سريعة

بيسجّل مواعيد المرضى؟

آه. بتحجز موعد، وبتشوف جدول اليوم.

بيقسّط الفاتورة؟

آه. دفعة أولى وأقساط شهرية، وبيوريك المتأخر.

بياناتي بأمان؟

آه. بيانات كل عيادة مقفولة عليها، وما حدا بيشوفها غيرك وغير فريقك.
