كل مشروع،
بحسابه لحاله.

دوام العمال، مصاريف الموقع، الشيكات والربح، لكل مشروع لحاله. مجاني، بالعربي.

نزّل دفترجرّب بدون تسجيل

شو بيعملك دفتر

  • حساب لكل مشروعميزانية المشروع، شو صرفت عليه، وقديش ضايل ربح.
  • دوام العمالمين إجا ومين غاب، واليوميات والسلف بتنحسب لحالها.
  • مصاريف الموقعحديد، إسمنت، ديزل، أجار معدات، مع صورة الفاتورة.
  • شيكات ورادار سيولةبيحكيلك قبل بأسابيع إذا رح تنقصك المصاري.
  • دفعات الزبونفواتير ودفعات وكشف حساب لصاحب المشروع.

أسئلة سريعة

بقدر أفصل حساب كل مشروع؟

آه. كل مشروع إله مصاريفه ودخله وعماله، وبتشوف ربحه لحاله.

بيحسب اليوميات والسلف؟

آه. من الدوام بيحسب أجرة كل عامل، وبيخصم السلف لحاله.

بيذكرني بالشيكات؟

آه. الشيكات الواردة والصادرة بتاريخ استحقاقها، وبينبهك قبل.
